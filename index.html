What Each Case Format Means

UPPER CASE
Every letter is capitalized. Example: MY VARIABLE NAME
lower case
Every letter is lowercased. Example: my variable name
Title Case
The first letter of each word is capitalized. Example: My Variable Name
Sentence case
Only the first letter of each sentence is capitalized. Example: My variable name
camelCase
The first word is lowercase and each subsequent word starts with a capital letter, with no separators. Example: myVariableName
PascalCase
Every word starts with a capital letter and there are no separators. Example: MyVariableName
snake_case
All words are lowercase and joined by underscores. Example: my_variable_name
kebab-case
All words are lowercase and joined by hyphens. Example: my-variable-name
CONSTANT_CASE
All words are uppercase and joined by underscores, used for constants. Example: MY_VARIABLE_NAME
dot.case
All words are lowercase and joined by periods. Example: my.variable.name
Alternating cAsE
Letters alternate between lowercase and uppercase. Example: mY vArIaBlE nAmE
iNVERSE cASE
Each letter's case is swapped from its original. Example: MY VARIABLE NAME becomes my variable name

Frequently Asked Questions

What is camelCase and when should I use it?

camelCase is a naming convention where the first word is lowercase and each subsequent word starts with a capital letter, with no spaces or separators (e.g., myVariableName). It is the standard naming convention for variables and functions in JavaScript, Java, and many other programming languages. Use camelCase when naming variables, function names, and object properties in your code.

What's the difference between Title Case and Sentence case?

Title Case capitalizes the first letter of every word (e.g., 'The Quick Brown Fox'), while Sentence case only capitalizes the first letter of each sentence (e.g., 'The quick brown fox'). Title Case is typically used for headings, book titles, and article names. Sentence case is used for regular body text and general writing.
