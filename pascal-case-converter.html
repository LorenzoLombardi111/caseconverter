PascalCase is a naming convention where every word begins with an uppercase letter and all words are joined together without any separator. For example, "user profile page" becomes UserProfilePage. PascalCase is sometimes called UpperCamelCase because it resembles camelCase but with the first letter also capitalized. The name "PascalCase" comes from the Pascal programming language, which popularized this convention.

PascalCase is the universal standard for naming classes in object-oriented programming. In Java, C#, TypeScript, Python, and Swift, class definitions use PascalCase. React component names must use PascalCase — it is how React distinguishes custom components from HTML elements. Angular services, directives, and pipes also follow PascalCase. If you build anything with classes or components, PascalCase is essential to your workflow.

When to Use PascalCase

Use PascalCase for class names, interface names, type aliases, enum names, and React/Vue/Angular component names. In C#, PascalCase is used even more broadly — for method names, property names, and namespaces. TypeScript interfaces and type definitions follow PascalCase by convention. When you create a new class or component, PascalCase is almost always the correct choice.

PascalCase is also used for file names in some ecosystems. React component files are commonly named after their component: UserProfile.tsx, ShoppingCart.jsx. C# class files follow the same pattern: UserService.cs, OrderController.cs. This makes it easy to locate the file containing a specific class.

Frequently Asked Questions

What is PascalCase?

PascalCase is a naming convention where every word starts with an uppercase letter and there are no separators between words. For example, "user profile page" becomes "UserProfilePage".

When should I use PascalCase?

PascalCase is used for class names in most programming languages including Java, C#, Python, and TypeScript. It is also the standard for React component names and Angular service names.

What is the difference between PascalCase and camelCase?

PascalCase capitalizes the first letter of every word including the first (UserProfilePage), while camelCase keeps the first word lowercase (userProfilePage). PascalCase is for classes and components; camelCase is for variables and functions.
