snake_case is a naming convention where all letters are lowercase and individual words are separated by underscores. For example, "user first name" becomes user_first_name. The style gets its name because the underscores connecting the words resemble a snake lying on the ground. It is one of the most readable multi-word formats because the underscores act as clear visual separators between words.

snake_case is the dominant naming convention in Python, where PEP 8 — the official Python style guide — mandates it for variable names, function names, and module names. It is also the standard in Ruby, Rust, and PHP. Database column names and SQL identifiers frequently use snake_case as well. If you work in any of these ecosystems, snake_case is not just a preference but a community requirement.

When to Use snake_case

Use snake_case for all variable names, function names, and method names in Python. PEP 8 is explicit about this, and linters like flake8 and pylint will flag violations. In Ruby, snake_case is used for methods, local variables, and file names. Rust uses snake_case for function names, variable bindings, and module names, enforced by the compiler's lint warnings.

Beyond programming, snake_case is common in database schemas. PostgreSQL, MySQL, and SQLite developers typically name their tables and columns in snake_case (e.g., user_id, created_at, order_total). File naming in many backend projects also follows snake_case: user_controller.py, database_helper.rb.

Frequently Asked Questions

What is snake_case?

snake_case is a naming convention where all letters are lowercase and words are separated by underscores. For example, "my variable name" becomes "my_variable_name".

Which programming languages use snake_case?

snake_case is the standard naming convention in Python, Ruby, Rust, and PHP. It is used for variable names, function names, and file names in these languages.

What is the difference between snake_case and kebab-case?

snake_case separates words with underscores (my_variable_name), while kebab-case separates words with hyphens (my-variable-name). snake_case is used in Python and Ruby; kebab-case is used in CSS and URL slugs.
